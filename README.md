## 🚀 Proyectos que estoy liderando

> 🔒 Repositorios privados: el código no es público, aquí tienes un resumen de cada proyecto.

### 🛒 SICOM / SICOM Postgre SQL
Plataforma integral para la gestión de compras, inventario y ventas. Cuenta con algoritmos avanzados de sugerencia de pedidos basados en rendimiento de ventas y una interfaz altamente optimizada para dispositivos móviles (responsive).
`PHP` `MySQL` `PostgreSQL`

### 👥 SIGH
Sistema robusto para la administración del talento humano, control de asistencia en tiempo real y automatización de procesos de nómina complejos, garantizando precisión y cumplimiento administrativo.
`Laravel` `Blade` `PHP` `MySQL`

### 🏪 MultiMarket POS
Sistema de Punto de Venta (POS) diseñado para la agilidad operativa en comercios. Enfocado en la eficiencia de transacciones, manejo de inventario en tiempo real y facilidad de uso para el operador.
`PostgreSQL` `PL/pgSQL` `PHP`

### 📊 Reportes de Ventas KLK
Herramienta especializada en el análisis y visualización de datos de ventas. Permite transformar datos crudos en métricas accionables para la toma de decisiones estratégicas.
`C#` `.NET`

### 🧾 FiscalBridge MMPOS
Puente de comunicación entre MultiMarket POS y las impresoras fiscales **The Factory HKA** (modelo HKA80 y compatibles). Traduce las operaciones del sistema al protocolo del equipo e incluye herramientas de diagnóstico de la conexión.
`C#` `.NET 9` `TfhkaNet` `Windows`

### 🖨️ Fiscal Printer Emulator
Emulador del **protocolo HKA80** que replica el comportamiento de la impresora fiscal real. Permite desarrollar y probar toda la capa fiscal sin depender del hardware físico, y está diseñado para incorporar nuevos modelos.
`C#` `.NET`

### 📱 App PrePedidos MMPOS
Aplicación móvil para levantar pre-pedidos directamente en el piso de venta. Las órdenes se registran desde el dispositivo y se integran al flujo del punto de venta.
`Flutter` `Dart`

### 📺 MMPOS SliderTV
App de **cartelería digital para TV** del ecosistema MultiMarket POS. Muestra promociones y contenido dinámico en las pantallas del local.
`Flutter` `Dart` `Android`

### 🌐 MultiMarketPOS.com
Sitio institucional del producto y **API de licencias**, encargada de la validación y gestión de las licencias de MultiMarket POS.
`Laravel` `Blade` `PHP`

### 🔐 Registro y Captura FS88H
Captura biométrica de huellas dactilares mediante el lector **Futronic FS88H**, que alimenta el sistema SIGH de Recursos Humanos.
`C#` `.NET` `WPF` `Futronic SDK`

### ✅ Verificador FS88H
Aplicación de escritorio para verificación de identidad por huella dactilar con lector **Futronic FS88H**. Valida al empleado contra la base biométrica al marcar entrada o salida, eliminando el fraude en el control de asistencia.
`C#` `.NET` `WPF` `Futronic SDK`

### 💳 BioPago Bridge
Integración **certificada** con BioPago y el BDV (Banco de Venezuela) para procesar cobros mediante verificación de huella dactilar.
`C#` `.NET`

### 🔄 SincroBD / SincroBD Multi
Sincronizador de bases de datos entre **Firebird y PostgreSQL**, manteniendo la información consistente entre motores distintos.
`C#` `.NET` `Firebird` `PostgreSQL`

### 🛍️ MelroseClo.com
Tienda de moda en línea con plugins de WordPress desarrollados a medida, integración con TikTok Shop y pasarelas de pago internacionales.
`WordPress` `WooCommerce` `PHP` `MySQL` `Redis` `nginx` `Cloudflare`

### 💪 MrFitnessScience.com
Sitio corporativo sobre WordPress con **tema y plugins desarrollados a medida**, adaptados a las necesidades de la marca.
`WordPress` `PHP`

### 📶 Portal Cautivo Ruijie Networks
Portal cautivo para redes WiFi gestionadas con equipos **Ruijie**, con **autenticación por SMS**: el visitante recibe un código en su teléfono para acceder a la red. Además de controlar el acceso, permite construir una base de contactos para campañas de marketing.
`PHP` `MySQL` `JavaScript` `API EnviosSMS`
